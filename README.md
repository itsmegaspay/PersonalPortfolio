# Personal portfolio

A single-page static portfolio. No build step.

## Customize
Open `index.html` and replace every placeholder: "Your Name", `you@example.com`, `your-username` links, the projects, experience and skills. Put your résumé at `resume.pdf` in this folder (or remove the button).

## Preview locally
Open `index.html` in a browser, or run `npx serve`.

## Deploy
Push to GitHub, then import the repo in Vercel (Framework preset: Other, no build command).
